## 写作原则

- **只写做过的**。没实操过的内容不写，避免二手转述。
- **记录取舍，不只记录结论**。为什么选 A 不选 B，比"A 很好"更有价值。
- **写清失败**。踩过的坑往往比成功经验更有参考价值。
